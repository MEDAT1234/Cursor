# Musical Notes - Lamen Neshki Hali / نوتات موسيقية - لمن نشكي حالي

This repository contains musical notation for "Lamen Neshki Hali" by Saad Lamjarred.

## Files

- `lamen_neshki_hali.abc` - Musical notation in ABC format
- `README_AR.md` - Detailed documentation in Arabic

## Song Information

- **Title**: Lamen Neshki Hali (لمن نشكي حالي)
- **Artist**: Saad Lamjarred (سعد المجرد)
- **Key**: D minor
- **Time Signature**: 4/4
- **Tempo**: 90 BPM

## How to Use

You can view and play the ABC notation file using:
- **EasyABC** - Free software for Windows/Mac/Linux
- **abcjs** - JavaScript library for web browsers
- **MuseScore** - Can import ABC files

## Important Note

⚠️ This is an interpretative and educational arrangement of the song, not an official or 100% accurate transcription. Created for educational and practice purposes only.

## Quick Start

```bash
# Convert to MIDI
abc2midi lamen_neshki_hali.abc -o lamen_neshki_hali.mid

# Convert to PDF
abcm2ps lamen_neshki_hali.abc -O lamen_neshki_hali.ps
ps2pdf lamen_neshki_hali.ps
```
