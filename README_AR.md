# نوتات موسيقية - لمن نشكي حالي

## معلومات الأغنية
- **العنوان**: لمن نشكي حالي (Lamen Neshki Hali)
- **الفنان**: سعد المجرد (Saad Lamjarred)
- **السلم الموسيقي**: ري مينور (D minor)
- **الإيقاع**: 4/4
- **السرعة**: 90 نبضة في الدقيقة

## الملفات المتوفرة

### 1. `lamen_neshki_hali.abc`
ملف النوتة الموسيقية بصيغة ABC notation. هذه الصيغة نصية يمكن قراءتها وتحويلها إلى نوتات موسيقية مرئية.

### 2. `lamen_neshki_hali_guitar.txt` 🎸
ملف تابات (Tablature) للجيتار بصيغة نصية ASCII. يحتوي على:
- جميع التوافقات المستخدمة بالتفصيل
- المقدمة الموسيقية
- المقاطع والكورس
- الجزء الإيقاعي السريع
- أنماط العزف (Strumming Patterns)

### 3. `GUITAR_PRO_GUIDE_AR.md` 📖
دليل شامل بالعربية لاستخدام Guitar Pro 5، يشمل:
- كيفية استيراد التابات إلى Guitar Pro 5
- شرح مفصل لجميع التوافقات
- نصائح للمبتدئين والمتقدمين
- تقنيات العزف المتقدمة
- جدول تدريب مقترح

## كيفية استخدام الملف

### عرض النوتات
يمكنك استخدام أحد البرامج التالية لعرض وتشغيل الملف:

1. **EasyABC** - برنامج مجاني لنظام Windows/Mac/Linux
2. **abcjs** - مكتبة JavaScript لعرض ABC notation في المتصفح
3. **MuseScore** - يمكنه استيراد ملفات ABC

### تحويل إلى PDF
```bash
# باستخدام abcm2ps و ps2pdf
abcm2ps lamen_neshki_hali.abc -O lamen_neshki_hali.ps
ps2pdf lamen_neshki_hali.ps
```

### تشغيل الموسيقى
```bash
# باستخدام abc2midi
abc2midi lamen_neshki_hali.abc -o lamen_neshki_hali.mid
```

## بنية الأغنية

1. **المقدمة الموسيقية** (Introduction)
   - لحن رئيسي يعتمد على السلالم: Dm - C - Bb - A7

2. **المقطع الأول** (Verse)
   - يبدأ بـ "لمن نشكي حالي"
   - نمط إيقاعي هادئ

3. **الكورس** (Chorus)
   - "يا ليل يا عين"
   - الجزء الأكثر حماساً من الأغنية

4. **الجزء الإيقاعي السريع**
   - قسم راقص بإيقاع أسرع

## ملاحظات مهمة

⚠️ **تنويه**: هذه النوتات هي تفسير تقريبي وتعليمي للأغنية وليست نسخة رسمية أو دقيقة بنسبة 100%. تم إنشاؤها لأغراض تعليمية وممارسة العزف فقط.

## التوافقات الموسيقية المستخدمة

- **Dm** (ري مينور) - D F A
- **C** (دو ماجور) - C E G
- **Bb** (سي بيمول ماجور) - Bb D F
- **A7** (لا سابع) - A C# E G
- **Gm** (صول مينور) - G Bb D
- **F** (فا ماجور) - F A C

## للمبتدئين

إذا كنت مبتدئاً في العزف:
1. ابدأ بتعلم التوافقات الأساسية (Dm, C, Bb, A7)
2. تدرب على المقدمة ببطء
3. استخدم مترونوم لضبط الإيقاع
4. اعزف كل قسم على حدة قبل دمجهم
