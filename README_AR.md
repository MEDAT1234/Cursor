# 🎵 بوت ASMR تيك توك الآلي

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

بوت ذكي يُنشئ فيديوهات ASMR عالية الجودة وينشرها تلقائياً على تيك توك دون أي تدخل يدوي.

## ✨ المميزات

- 🎬 **إنشاء فيديوهات تلقائي**: ينشئ فيديوهات ASMR مذهلة مع مرئيات مخصصة
- 🔊 **5 أنواع من ASMR**: أصوات المطر، النار، أمواج البحر، الكتابة على لوحة المفاتيح، والهمس
- 🎨 **مرئيات جميلة**: تدرجات متحركة وتأثيرات جزيئات
- 📱 **نشر تلقائي**: يرفع على تيك توك مع التعليقات والهاشتاقات
- ⏰ **جدولة**: حدد أوقات نشر متعددة خلال اليوم
- 🤖 **آلي 100%**: لا يحتاج تدخل بعد الإعداد
- 📊 **تسجيل**: يتتبع جميع الأنشطة والأخطاء
- 🎯 **محسّن لمحركات البحث**: تعليقات تلقائية مع هاشتاقات رائجة

## 🎥 أنواع ASMR

يُنشئ البوت الأنواع التالية من محتوى ASMR:

1. **أصوات المطر** 🌧️ - مطر مهدئ مع قطرات عرضية
2. **طقطقة النار** 🔥 - أجواء مدفأة دافئة
3. **أمواج المحيط** 🌊 - أصوات شاطئ هادئة
4. **الكتابة على لوحة المفاتيح** ⌨️ - ASMR لوحة مفاتيح مُرضي
5. **الهمس الناعم** 💜 - أصوات تنفس وهمس لطيفة

كل فيديو يتضمن:
- خلفية متحركة بتدرج مخصص
- نصوص احترافية
- تعليقات تلقائية
- هاشتاقات رائجة
- مدة 15-60 ثانية (قابلة للتخصيص)
- صيغة عمودية (1080×1920) مثالية لتيك توك

## 🚀 دليل البدء السريع

### المتطلبات الأساسية

- Python 3.8 أو أحدث
- حساب تيك توك
- Windows 10/11

### التثبيت على Windows

#### الخطوة 1: التحقق من Python

افتح موجه الأوامر (Command Prompt):
```batch
python --version
```

**ليس لديك Python؟** حمّله من: https://www.python.org/downloads/
⚠️ **مهم:** ضع علامة على "Add Python to PATH" أثناء التثبيت

#### الخطوة 2: انتقل إلى مجلد المشروع

```batch
cd C:\Users\YourName\Desktop\workspace
```

#### الخطوة 3: تشغيل سكريبت الإعداد

```batch
setup.bat
```

انتظر حتى ترى: `✅ Setup complete!`

#### الخطوة 4: تفعيل البيئة الافتراضية

```batch
venv\Scripts\activate.bat
```

ستظهر `(venv)` في بداية السطر

#### الخطوة 5: اختبار الفيديو

```batch
python bot.py --mode test
```

سيُنشئ فيديو اختبار في مجلد `generated_videos`

#### الخطوة 6: نشر أول فيديو

```batch
python bot.py --mode once
```

**ما سيحدث:**
1. سيُفتح متصفح Chrome تلقائياً
2. سجّل دخول إلى تيك توك
3. ارجع لموجه الأوامر واضغط Enter
4. سيُنشئ البوت الفيديو وينشره

**مهم جداً:** احفظ معرف الجلسة الذي يظهر:
```
💾 Save this session ID for future use:
   TIKTOK_SESSION_ID=abc123xyz...
```

أضفه إلى ملف `.env`:
```batch
notepad .env
```

أضف السطر:
```env
TIKTOK_SESSION_ID=abc123xyz...
```

#### الخطوة 7: تشغيل الوضع الآلي

```batch
start_bot.bat
```

**تم!** البوت يعمل الآن وسينشر في:
- 🌅 الساعة 9:00 صباحاً
- ☀️ الساعة 2:00 ظهراً
- 🌙 الساعة 8:00 مساءً

**للإيقاف:** اضغط `Ctrl+C`

## ⚙️ التخصيص

عدّل ملف `.env`:

```batch
notepad .env
```

### إعدادات مهمة:

```env
# أوقات النشر (صيغة 24 ساعة)
POST_TIMES=09:00,14:00,20:00

# أنواع ASMR المطلوبة
ASMR_TYPES=rain,fire,waves,typing,whisper

# إعدادات الفيديو
VIDEO_WIDTH=1080
VIDEO_HEIGHT=1920
VIDEO_DURATION=15
FPS=30

# معرف جلسة تيك توك
TIKTOK_SESSION_ID=your_session_id_here
```

## 🔧 حل المشاكل

### "python: command not found"

**الحل:**
```batch
REM جرب بدون الرقم 3
python --version
python bot.py --mode test
```

### "Le chemin d'accès spécifié est introuvable"

**الحل:** نسيت تشغيل setup.bat
```batch
setup.bat
```

### فشل إنشاء الفيديو

**الحل:** تثبيت ffmpeg
1. حمّل من: https://www.gyan.dev/ffmpeg/builds/
2. استخرج إلى `C:\ffmpeg`
3. أضف `C:\ffmpeg\bin` إلى PATH
4. أعد تشغيل Command Prompt

### المتصفح لا يفتح

**الحل:**
```batch
venv\Scripts\activate.bat
playwright install chromium
```

### فشل الرفع على تيك توك

**الحل:**
1. احذف `TIKTOK_SESSION_ID` من `.env`
2. شغل `python bot.py --mode once` مجدداً
3. سجل دخول عند فتح المتصفح
