Quick Steps:
============

1️⃣  SETUP (First Time Only - 2 minutes)
   
   Linux/macOS:
   -----------
   cd /workspace
   chmod +x setup.sh
   ./setup.sh

   Windows:
   --------
   cd \workspace
   setup.bat


2️⃣  ACTIVATE ENVIRONMENT (Every Time)

   Linux/macOS:
   -----------
   source venv/bin/activate

   Windows:
   --------
   venv\Scripts\activate.bat


3️⃣  TEST (No Upload - 1 minute)

   Linux/macOS:
   -----------
   python3 bot.py --mode test

   Windows:
   --------
   python bot.py --mode test

   → Creates test video in generated_videos/ folder


4️⃣  POST FIRST VIDEO (With TikTok Login - 2 minutes)

   Linux/macOS:
   -----------
   python3 bot.py --mode once

   Windows:
   --------
   python bot.py --mode once

   → Browser opens automatically
   → Login to TikTok
   → Press Enter in terminal
   → Bot posts video
   → Save the session ID shown!


5️⃣  RUN AUTOMATED (Posts at 9am, 2pm, 8pm daily)

   Linux/macOS:
   -----------
   ./start_bot.sh

   Windows:
   --------
   start_bot.bat

   → Bot now runs 24/7!
   → Press Ctrl+C to stop


6️⃣  MONITOR

   View logs:
   ----------
   tail -f bot.log           (Linux/macOS)
   
   Check videos:
   ------------
   ls generated_videos/      (Linux/macOS)
   dir generated_videos      (Windows)
